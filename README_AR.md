# صوت إلى نص — إصدار GitHub Pages المجاني (محدّث)

هذا إصدار **ثابت بالكامل** (HTML/CSS/JavaScript) ولا يحتاج إلى Node.js أو Python أو خادم API. يستخدم Transformers.js لتشغيل نموذج Whisper داخل المتصفح، لذلك لا توجد رسوم API ولا تُرسل الملفات الصوتية إلى خادم للتفريغ. يحتاج المتصفح إلى اتصال بالإنترنت لتحميل مكتبة التشغيل وملفات النموذج أول مرة.

## النشر على GitHub Pages

1. نزّل `sawt-text-github-pages.zip` وفك الضغط عنه.
2. سجّل الدخول إلى GitHub وأنشئ مستودعًا جديدًا، مثل `sawt-text`.
3. ارفع **كل محتويات هذا المجلد** إلى جذر المستودع؛ يجب أن يكون `index.html` في الجذر مباشرة، وليس داخل مجلد فرعي.
4. افتح **Settings → Pages**.
5. ضمن **Build and deployment** اختر **Deploy from a branch**.
6. اختر الفرع `main` والمجلد `/(root)` ثم اضغط **Save**.
7. انتظر حتى ينتهي النشر وافتح العنوان الذي يعرضه قسم Pages، عادةً `https://اسمك.github.io/sawt-text/`.

## الاستخدام

- افتح الموقع عبر رابط HTTPS المنشور على GitHub Pages.
- أضف ملفات صوت أو فيديو؛ غيّر الترتيب باستخدام الأسهم أو السحب والإفلات.
- اختر اللغة والنموذج، ثم اضغط بدء التفريغ.
- عدّل النصوص في مربعات النتائج، ثم نزّلها TXT أو Word.

## ملاحظات مهمة

- مكتبة التشغيل: [`@huggingface/transformers`](https://github.com/huggingface/transformers)؛ يستخدم التطبيق `q8` لتقليل استهلاك الذاكرة على المتصفح، ويعرض رسالة الخطأ التفصيلية لكل ملف عند الفشل. النماذج: [`onnx-community/whisper-tiny`](https://huggingface.co/onnx-community/whisper-tiny)، [`whisper-base`](https://huggingface.co/onnx-community/whisper-base)، و[`whisper-small`](https://huggingface.co/onnx-community/whisper-small).
- GitHub Pages يستضيف الملفات الثابتة فقط ولا يشغّل خادم Python أو Node.js. لذلك يعتمد هذا الإصدار على قدرة المتصفح وجهاز الزائر بدل الخادم.
- تنزيل النموذج أول مرة قد يكون كبيرًا ويعتمد زمنه على اتصال الإنترنت. يُعاد استخدام التخزين المؤقت للمتصفح ما أمكن.
- الملفات الصوتية تُفك إلى ذاكرة المتصفح قبل التفريغ؛ التسجيلات الطويلة جدًا قد تستهلك ذاكرة كثيرة أو تفشل على الأجهزة محدودة الموارد. للفيديو، يُستخرج الصوت بواسطة مشغّل المتصفح وقد يستغرق الاستخلاص تقريبًا مدة تشغيل الفيديو. بعض صيغ الفيديو لا يدعمها كل متصفح.
- أنصح بمتصفح Chrome أو Edge حديث على كمبيوتر. جودة النتائج تختلف حسب اللغة واللهجة والضوضاء والنموذج، ولا توجد دقة مضمونة 100%.
- هذا المشروع يحمّل نماذج من Hugging Face ومكتبة من jsDelivr. تنزيل هذه الملفات يحتاج اتصالًا بالإنترنت، لكن لا يتطلب مفتاح API.

## استكشاف الأخطاء

- **فشل تحميل محرك التفريغ أو ظهور `Failed to fetch`:** النسخة المحدّثة تجرب تحميل مكتبة التشغيل من `cdn.jsdelivr.net` ثم `esm.sh`، وتعرض سبب الخطأ أسفل بطاقة الملف ولا تمسحه برسالة نجاح. تأكد من الاتصال بالإنترنت وأن الشبكة لا تحجب `cdn.jsdelivr.net` أو `esm.sh` أو `huggingface.co`، ثم أعد تحميل الصفحة. جرّب أيضًا نموذج Tiny. إذا ظهرت تفاصيل تقنية تحت الملف، انسخها لتشخيص المشكلة.
- **الذاكرة غير كافية:** جرّب Tiny، أو قسّم التسجيل إلى أجزاء أصغر، وأغلق التبويبات الأخرى.
- **فشل قراءة الفيديو:** جرّب Chrome/Edge وحدّث المتصفح، أو حوّل الفيديو إلى MP3/WAV باستخدام أداة محلية.
- **الموقع لا يعمل من فتح `index.html` مباشرة:** استخدم رابط GitHub Pages المنشور بنظام HTTPS؛ الاستيراد من CDN قد لا يعمل عند فتح الملف محليًا.


## تحديث موقعك إذا كان منشورًا بالفعل على GitHub Pages

إذا رفعت النسخة السابقة بالفعل، فلن تتغير الصفحة المنشورة تلقائيًا. نزّل النسخة المحدّثة، وافتح مستودع GitHub، ثم ارفع ملف `index.html` الجديد إلى جذر المستودع مع الموافقة على استبدال النسخة القديمة، ثم اضغط **Commit changes**. بعد اكتمال النشر، افتح الموقع وأجرِ تحديثًا قويًا للصفحة (`Ctrl+Shift+R`). وإذا فشل التفريغ مجددًا، سيظهر السبب التقني داخل بطاقة الملف؛ أرسل نصّه للمساعدة في تحديد المشكلة.
